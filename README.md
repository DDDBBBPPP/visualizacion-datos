# Visualización de datos

Proyecto de visualización de datos utilizando **Matplotlib, Seaborn y Streamlit**.

El objetivo es representar cinco tipos de gráficos, comparar su implementación con distintas bibliotecas y mostrarlos en una aplicación web interactiva.

## Gráficos incluidos

1. **Barras agrupadas:** ventas simuladas de videojuegos.
2. **Líneas:** temperaturas históricas de estaciones meteorológicas.
3. **Histograma:** distribución de calificaciones simuladas.
4. **Dispersión:** medidas de flores del dataset Iris.
5. **Burbujas:** potencia, eficiencia y peso de automóviles.

## Contenido del repositorio

- `app.py`: aplicación principal de Streamlit.
- `graficos/`: código Python de cada gráfico.
- `datos/`: archivos de datos utilizados.
- `requirements.txt`: bibliotecas necesarias para ejecutar la aplicación.
- **Cuaderno de Google Colab:** comparación de los cinco gráficos con Matplotlib y Seaborn.

## Aplicación web

La aplicación permite navegar entre los cinco gráficos, seleccionar la biblioteca de visualización y utilizar filtros interactivos.
