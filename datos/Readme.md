# Datos del proyecto

Esta carpeta contiene los archivos de datos utilizados en las visualizaciones.

## Archivos

- **`1921.CSV`:** registros meteorológicos históricos de estaciones españolas correspondientes a 1921. Se utilizan para representar la evolución de las temperaturas.

## Otros conjuntos de datos

El proyecto también utiliza:

- **Videojuegos:** ventas simuladas generadas en Python.
- **Calificaciones:** notas simuladas generadas con NumPy.
- **Iris:** medidas de flores obtenidas mediante Scikit-learn.
- **Auto MPG:** características de automóviles obtenidas mediante Seaborn.

Estos conjuntos de datos se cargan o generan directamente desde el código Python y no necesitan archivos adicionales en esta carpeta.
